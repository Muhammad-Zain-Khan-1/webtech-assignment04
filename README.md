# Markdown Slides App

Web Technologies - Assignment 04.

Write slides in Markdown, see them live in preview section, save them in the browser's history, and present them in full screen.

## Usage
1. Open `index.html` in a browser.
2. Type Markdown in the editor. Use `---` on its own line to start a new slide.
3. Click **Save Slides** (or press Ctrl+S) to store them in the browser.

## Shortcuts
- Left / Right Arrow: previous / next slide ( click on slide preview section to active arrow keys )
- F11: full screen / Presentaion view
- Ctrl + S: save

## Markdown supported
`#`, `##`, `###` for headings, `**bold**`for bold, and `\n` for line breaks.
